# EHTID Game Lab — ALPHA 0.4.1 · Windows x64

**Редактор сейвов + экспериментальный Live Memory Editor для одиночных игр**

Это АЛЬФА. Совместимость со всеми играми не гарантируется. Работай только со своими локальными сохранениями и офлайн-играми, не используй с античитом или на серверах.

## 1. Запуск на ПК

1. Требуется **Windows 10/11 x64**. Скачай артефакт **EHTID-GameLab-Alpha-Windows-Overlay** из GitHub Actions.
2. Распакуй **весь ZIP** в отдельную папку (например, C:\Games\EHTID-GameLab-Alpha). Не запускай приложение прямо внутри архива.
3. Открой **game_lab.exe**. Рядом должны находиться **EHTID-MemoryHelper.exe**, **EHTID-Overlay.exe**, **flutter_windows.dll**, папка **data** и эта инструкция.
4. .NET устанавливать отдельно не требуется: помощник публикуется как self-contained x64. Права администратора специально не запрашиваются.
5. Если Windows или антивирус блокирует помощник, **не отключай защиту**. Проверь происхождение архива и ограничься файловым редактором, если доверия нет.

## 2. Редактирование сейвов

1. Сделай резервную копию мира/профиля и **закрой игру**.
2. Выбери **«Редактор сохранений» → «Открыть папку игры»**. Можно подключить несколько папок для поиска.
3. На ПК сейвы часто лежат не в папке с EXE: проверь AppData/Roaming, AppData/Local, AppData/LocalLow, Documents/My Games, Saved Games. Кнопка поиска каталогов Windows предложит совпадающие с названием игры папки; добавление потребует подтверждения.
4. Для JSON/текста отредактируй нужное поле и проверь результат. Для бинарного SAV/DAT открой файл и нажми **«Найти и изменить число в сейве»**. Выбери значение, Int32/Float32, порядок байтов LE/BE и конкретное смещение.
5. Перед записью редактор сверит исходные байты, спросит подтверждение, создаст рядом резервную копию **.ehtid-backup-*.bak** и перечитает записанное.
6. Шифрованные, сжатые и подписанные сейвы не обещаем автоматически расшифровывать.

## 3. Читы — изменение памяти офлайн-игры Windows

1. Открой свою **одиночную игру** в окне или режиме без рамки и посмотри текущее число, например 120 HP, 75 маны, 750 монет.
2. В EHTID открой **«Читы (соло)» → «Live Memory · Windows»**, нажми **«Найти окна»** и выбери именно игру по названию и PID.
3. Введи число (например 120). Выбери формат: **Int32** для обычных целых, **Int64** для больших целых, **Float32** для дробных HP/маны/энергии, **Float64** для двойной точности.
4. Нажми **«Первый поиск»**. Большое количество совпадений ещё не означает, что найден реальный HP.
5. Вернись в игру и **измени показатель естественным способом** (например получи урон: HP стал 97). Введи 97 и нажми **«Уточнить»**. Повторяй, пока кандидатов не станет мало.
6. Нажми на нужный адрес, введи новое число (например 9999) и подтверди, что это твоя офлайн-игра. Программа проверит старые байты, запишет **только один выбранный адрес** и перечитает результат.
7. **«Откатить запись»** попытается вернуть старое число, если игра не изменила его после записи. После перезапуска игры адреса часто меняются — ищи заново.

Поиск ограничен разрешёнными Windows областями и выбранным бюджетом RAM (по умолчанию 512 МиБ). Если значение находится за пределами бюджета, защищено или пересчитывается, результат может отсутствовать. Повышение лимита увеличивает время поиска. Неверный адрес может вызвать вылет игры.

### Выбор числа со скриншота

Нажми **«Выбрать число на скриншоте»**. На Windows можно сделать снимок с задержкой 4 секунды (переключись в игру), нажать на цифру на снимке и подтвердить значение. При наличии установленного локального **Tesseract OCR** приложение попробует распознать цифру; Tesseract не входит в архив. Можно ввести число вручную.

**Скриншот и живой оверлей — разные функции.** Скриншот лишь помогает заполнить число; он не определяет адрес RAM. Отдельный плавающий оверлей описан в разделе 6: адрес там тоже нужно искать, уточнять и подтверждать вручную.

## 4. Решение проблем

- **Нет EHTID-MemoryHelper.exe:** распакуй весь ZIP, не перемещай один EXE.
- **Игра не найдена:** открой игровое окно, нажми «Найти окна»; список ограничен видимыми окнами.
- **Доступ к процессу запрещён:** Windows отказала в чтении/записи, обход защит и повышение привилегий не предусмотрены.
- **0 совпадений:** выбери другой тип, проверь точное число и лимит сканирования.
- **Много совпадений:** измени значение в игре, повторяй «Уточнить»; не меняй все адреса подряд.
- **Запись отказана:** игра могла изменить память между поиском и записью. Уточни повторно или откажись от правки.
- **Сейв испорчен:** закрой игру и восстанови оригинальный файл из резервной копии .ehtid-backup-*.bak.
- **Эффекта нет после перезапуска:** изменения памяти обычно не постоянны.

## 5. Ограничения альфы

Нет обхода античита/DRM, доступа к серверной экономике, принудительного открытия защищённых процессов, автоматической заморозки значений, поиска цепочек указателей и автоматического выбора адреса RAM по координатам игрового HUD. Не все файлы SAV, SQLite или закрытые контейнеры можно редактировать. Никакие данные сканирования памяти не отправляются в интернет. Отдельная функция перевода, если включена, обращается к указанному пользователем LibreTranslate-серверу.

## 6. Плавающий RAM-редактор поверх Windows-игры

1. Запусти одиночную игру **в оконном или безрамочном режиме**. Эксклюзивный полноэкранный режим может перекрывать любые сторонние окна.
2. В **EHTID Game Lab → Читы (соло)** нажми **«Открыть поверх игры»**. Откроется отдельное небольшое окно **EHTID · плавающий редактор**, закреплённое над другими окнами. Можно также запустить **EHTID-Overlay.exe** вручную из того же ZIP.
3. Нажми **«Найти игры»**, выбери процесс, введи число и формат Int32/Int64/Float32/Float64. Запусти **«Первый поиск»**.
4. После изменения числа в игре введи новое число и нажми **«Уточнить»**. Выбери единственный подтверждённый адрес, впиши желаемое значение и нажми **«Записать адрес»**.
5. Перед записью оверлей покажет предупреждение и попросит подтверждение. Старое значение сверяется побайтово; после записи выполняется проверка. Кнопка **«Откат»** пытается вернуть последнее значение, только если оно всё ещё совпадает с записанным.
6. Панель можно переместить, свернуть или временно отключить закрепление кнопкой **«Поверх всех»**.

Оверлей **не захватывает ввод в игре**, **не читает её экран** и **не привязан напрямую к координатам HUD**. Нельзя просто нажать на число в игре и мгновенно изменить его: сначала нужно найти адрес поиском и уточнением. Инъекции и обход защит не используются. Для полноэкранных игр применяй режим «без рамки».
