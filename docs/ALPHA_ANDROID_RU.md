# EHTID Game Lab Alpha 0.4.1 — Android

**Версия:** Android APK, интерфейс с оригинальной иконкой и тёмно-фиолетовой темой.

## Установка

1. Скачай из GitHub Actions артефакт **EHTID-GameLab-Android-Overlay-APK** и распакуй ZIP.
2. Установи `app-release.apk`. На Xiaomi/POCO система может предложить подтвердить установку из доверенного источника.
3. Открой **Читы (соло)** — здесь находится управление плавающим значком.
4. Нажми **«Запустить поверх игры»**. При первом запуске появятся системные настройки **«Показывать поверх других приложений»**. Разреши для EHTID, вернись в приложение и повторно нажми кнопку.
5. Значок **E** можно перетаскивать поверх других приложений. Нажми на него, чтобы открыть панель. Введи видимые на экране HP, ману или валюту. Кнопка **«Открыть редактор»** возвращает в EHTID и передаёт введённое число. Кнопки **«−»** и **«×»** сворачивают и останавливают окно.
6. При необходимости открой папку сейвов через системный Android SAF-picker и ищи указанное значение в **доступных** файлах. Для текстовых/JSON и некоторых бинарных сейвов можно подтвердить точечное изменение с резервной копией.

## Чего Android-оверлей не делает

Это плавающее окно для ручного ввода, **не универсальный чит для других Android-игр**. Обычное приложение Android не может читать или менять оперативную память другой игры. Никакие обходы sandbox/root/античита не встроены. Панель не читает скрыто содержимое чужих окон, не делает тайных скриншотов и не видит HP без твоего ввода.

Для считывания числа со снимка можно воспользоваться обычным системным скриншотом и кнопкой выбора изображения в редакторе; на Android в этой версии нет встроенного автоматического OCR чужого экрана. Для доступа к Android/data, Android/obb и закрытым файлам игр могут действовать системные ограничения, даже после выбора папки.

## Защита и ограничения

- Не меняй сейв, когда игра продолжает в него писать.
- Сделай копию профиля перед испытанием альфы.
- Если игра использует шифрование/сжатие/контрольные суммы, поиск числа может ничего не найти.
- Системное разрешение оверлея можно отозвать в **Настройки → Приложения → Специальный доступ → Поверх других окон** (названия пунктов различаются).
- Оверлей работает как видимая фоновая служба, оставляет уведомление и останавливается кнопкой «×» или «Остановить» в приложении. Если телефон выгрузит службу из-за экономии батареи, запусти её снова.
- Некоторые полноэкранные приложения не отображают сторонние оверлеи из-за своей политики защиты или системных ограничений.
