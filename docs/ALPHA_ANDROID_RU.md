# EHTID Game Lab Alpha 0.4.13 — Android

**Версия:** Android APK, интерфейс с оригинальной иконкой и тёмно-фиолетовой темой.

## Установка

1. Открой [GitHub Releases](https://github.com/craftkot/Hik/releases) и скачай установочный APK последнего выпуска напрямую. Ссылки Actions Artifacts не требуются.
2. Установи скачанный `EHTID-GameLab-Android-v*.apk`. На Xiaomi/POCO система может предложить подтвердить установку из доверенного источника.
3. Открой **Читы (соло)** — здесь находится управление плавающим значком.
4. Нажми **«Запустить поверх игры»**. При первом запуске появятся системные настройки **«Показывать поверх других приложений»**. Разреши для EHTID, вернись в приложение и повторно нажми кнопку.
5. Значок **E** можно перетаскивать поверх других приложений. Нажми на него, чтобы открыть панель. Введи видимые на экране HP, ману или валюту. Кнопка **«Открыть редактор»** возвращает в EHTID и передаёт введённое число. Кнопки **«−»** и **«×»** сворачивают и останавливают окно.
6. При необходимости открой папку сейвов через системный Android SAF-picker и ищи указанное значение в **доступных** файлах. Для текстовых/JSON и некоторых бинарных сейвов можно подтвердить точечное изменение с резервной копией.

## Чего Android-оверлей не делает

Это плавающее окно для ручного ввода, **не универсальный чит для других Android-игр**. Обычное приложение Android не может читать или менять оперативную память другой игры. Никакие обходы sandbox/root/античита не встроены. Панель не читает скрыто содержимое чужих окон, не делает тайных скриншотов и не видит HP без твоего ввода.

Для считывания числа со снимка можно воспользоваться обычным системным скриншотом и кнопкой выбора изображения в редакторе; на Android в этой версии нет встроенного автоматического OCR чужого экрана. Для доступа к Android/data, Android/obb и закрытым файлам игр могут действовать системные ограничения, даже после выбора папки.

## Защита и ограничения

- Не меняй сейв, когда игра продолжает в него писать.
- Сделай копию профиля перед испытанием альфы.
- Если игра использует шифрование/сжатие/контрольные суммы, поиск числа может ничего не найти.
- Системное разрешение оверлея можно отозвать в **Настройки → Приложения → Специальный доступ → Поверх других окон** (названия пунктов различаются).
- Оверлей работает как видимая фоновая служба, оставляет уведомление и останавливается кнопкой «×» или «Остановить» в приложении. Если телефон выгрузит службу из-за экономии батареи, запусти её снова.
- Некоторые полноэкранные приложения не отображают сторонние оверлеи из-за своей политики защиты или системных ограничений.

## Проверка поиска по нескольким папкам (исправление Alpha)

1. В EHTID выбери **папку A**, содержащую копию небольшого читаемого сейва; программа должна показать файлы.
2. Через значок папки с плюсом добавь **папку B**, содержащую другой сейв. Системные разрешения Android предоставь отдельно для каждой папки.
3. Найди известное число в файле A, затем открой файл B, затем **снова файл A**. Оба должны читаться без ошибки «Document not found».
4. Для проверки безопасной записи используй **тестовый сейв**: в папке A измени выбранное значение. Редактор должен создать резервную копию **в папке A**, а не B.
5. Пересканируй папки и проверь, что всё ещё можно открыть файлы каждой из них. После перезапуска приложения папки необходимо снова добавить в список, даже если Android сохранил системные разрешения.

Важно: выбор одной папки **не даёт доступа ко всем файлам телефона**; Android может ограничивать выбор отдельных системных или игровых директорий. Если провайдер отозвал разрешение, повторно выбери нужную папку.


## Проверка изменений сейвов в Alpha 0.4.3

Редактор теперь передаёт исходные байты сохранения системному SAF-модулю и повторно сверяет их **до создания/записи резервной копии и непосредственно перед изменением оригинала**. Если игра успела обновить сейв, запись прервётся, чтобы не затереть новые данные. Разрешения Android по-прежнему распространяются только на выбранные папки.

## Приоритетные значения в сейвах (Alpha 0.4.5)

В редакторе JSON-полей доступных Android-сейвов значения, похожие по названию на валюту, HP, ману, характеристики, опыт и уровень, помечаются и выводятся выше остальных. Поиск по выбранным через SAF папкам также выделяет явные числовые присваивания. Это **подсказка по имени поля**, а не доказательство назначения значения в игре. Сортировка не меняет сами файлы и не предоставляет доступ к RAM чужих приложений.

## Фильтрация полей JSON — Alpha 0.4.6

В редакторе сохранений открой JSON-файл и нажми **«Редактировать поля JSON»**. Вверху окна найди поле **«Поиск по ключу или значению»**, переключатель **«Только важные»** и категории («Валюта», «HP / здоровье», «Мана / MP», «Характеристики», «Уровень», «Опыт», «Ресурсы»). Фильтры можно сочетать; кнопка **«Все»** отменяет выбор категории. Если совпадений нет, нажми **«Сбросить фильтры»**. Нажатие по полю открывает прежний редактор с подтверждением. Никаких автоматических изменений или записи в сейв фильтрация не выполняет.


## Alpha 0.4.7 и Android

В выпуске 0.4.7 новый режим чтения текущих значений RAM доступен **только на Windows**. Android APK сохраняет функции редактора сейвов, фильтров JSON-полей и ручного плавающего ввода из 0.4.6. Приложение не читает память других игр: обычные Android-разрешения на оверлей и доступ к выбранным SAF-папкам не предоставляют таких прав.


## Выбор игры вместо поиска папки — Alpha 0.4.8

В редакторе сохранений для Android нажми кнопку **«Игра»**. Выбери установленную игру в списке (можно искать по названию или package ID). EHTID проверит уже разрешённые через системный SAF папки и покажет файлы, путь которых похож на название/пакет игры. Нестандартные расширения тоже отображаются, поскольку игра может назвать сейв как угодно. Результат — лишь кандидаты; перед изменением проверь содержимое и сделай копию.

Если список пуст, используй соседнюю кнопку папки и разреши доступ к **публичной папке** игры, если Android позволяет это сделать. Если сначала выбрать игру, а затем нажать значок папки вверху, разрешённый каталог будет **привязан именно к этой игре** и сохранён для следующих запусков. Повторно разрешать эту папку не понадобится, пока Android хранит доступ. Частные данные чужих приложений в `/data/data`, закрытые `Android/data` и `Android/obb` без дополнительных привилегий недоступны: выбор иконки приложения не является разрешением на их чтение. Для списка используется только видимость приложений с кнопкой запуска, без `QUERY_ALL_PACKAGES`. Это новая функция версии 0.4.8; в опубликованной 0.4.7 её ещё нет.


## Перевод выбранной игры — Alpha 0.4.9

1. Открой **«Перевод игры»**, нажми **«Игра»** и выбери установленное приложение. EHTID найдёт JSON-локализации в уже разрешённых SAF-папках; если результатов нет, нажми **«Доступ к папке игры»** и выбери доступный каталог через системный проводник Android.
2. По умолчанию активен **перевод на телефоне (Google ML Kit)**. Укажи язык оригинала: английский, японский, китайский или корейский. Целевой язык по умолчанию — русский. При первом использовании потребуется загрузить языковые модели через интернет; после загрузки перевод строк выполняется на устройстве, без собственного сервера и без API-ключа.
3. Если нужен другой движок, выключи режим ML Kit и укажи **HTTPS-адрес своего LibreTranslate** (при необходимости API-ключ). В этом режиме текст отдельных строк отправляется серверу перевода, который ты указал.
4. Нажми **«Подготовить перевод»**. Программа обработает до 6 доступных JSON-файлов и до 100 строк каждого за один запуск (файл до 1 МБ). Поддерживаются только открытые локализации, не бинарные игровые пакеты.
5. Проверь предпросмотр, закрой игру и отдельно подтверди применение. Перед каждой записью создаётся резервная копия; изменившийся после просмотра оригинал переписан не будет. Ошибки записи отображаются отдельно — возможен частичный перевод нескольких файлов.

**Ограничения:** выбор значка игры сам по себе не даёт доступа к `/data/data`, закрытым `Android/data`, `Android/obb`, APK, зашифрованным/сжатым ресурсам и серверному тексту. Некоторые игры загружают локализацию из подписанных пакетов или обновляют файлы при запуске, и такой способ перевода у них не сработает. ML Kit использует машинный перевод, поэтому проверяй контекст и плейсхолдеры. Если на телефоне нет доступа к загрузке модели, попробуй свой LibreTranslate.


## Специальный доступ ко всем файлам — Alpha 0.4.10

В Android 11+ в разделе сохранений, предзагрузок и перевода EHTID покажет запрос **«Доступ ко всем файлам»**. Нажми **«Выдать разрешение»**, включи переключатель для приложения EHTID Game Lab в открывшихся системных настройках и вернись назад. После возвращения программа сама обновит статус. Разрешение можно отозвать в настройках телефона.

Это разрешение расширяет возможности работы с **общей памятью телефона**, но не открывает закрытые `/data/data`, `Android/data` и `Android/obb` чужих приложений. В этом выпуске поисковик сейвов и редактор **по-прежнему используют папки, предоставленные через SAF**; одно разрешение само по себе не запускает сканирование всего телефона. Если не выдавать доступ, старый способ работы останется доступен. На Android 10 и более старых версиях применяется SAF без этого запроса.


## Ручной выбор папки — Alpha 0.4.11

Если EHTID не показывает установленные игры, просто нажми **«Папка»** в верхней части Android-редактора или переводчика и выбери доступную папку вручную. В окне списка игр тоже есть кнопка **«Нет игры? Выбрать папку вручную»**. Редактор теперь показывает все файлы этой папки, даже если их расширения не похожи на обычные сейвы. Переводчик больше не требует, чтобы игра отображалась среди установленных приложений: для подготовки перевода достаточно открытой папки с JSON-локализацией. Системный SAF по-прежнему не открывает закрытые данные других игр в `/data/data`, `Android/data` и `Android/obb`.


## Контейнер игр на Android — Alpha 0.4.12

Новая вкладка **«Контейнер игр»** работает **только на Android**. Кнопка «Создать тестовую игру» добавляет HTML5-игру с монетами в приватное хранилище EHTID; её можно запустить внутри EHTID и проверить сохранение счёта после перезапуска. Есть импорт ZIP с `index.html` и импорт отдельного APK. **APK устанавливается через обычный Android installer и запускается отдельно** — это не виртуализатор и не способ получить доступ к закрытым сейвам. Windows-версия не получает новой вкладки. Подробности в `docs/RELEASE_NOTES_RU.md`.


## Большие APK — Android Alpha 0.4.13

Во вкладке **«Контейнер игр» → «Импорт ZIP / APK»** теперь принимаются одиночные APK размером до **8 ГиБ** при достаточном свободном месте. Вместо загрузки целого APK в ОЗУ используется потоковое копирование блоками. Отображается процент загрузки/объём, если системный провайдер сообщает размер, или просто скопированные МиБ. Перед началом и по ходу копирования проверяется запас памяти минимум **256 МиБ**; неудачный импорт удаляет неполную копию. Для HTML5 ZIP остаются лимиты **200 МиБ на ZIP**, **50 МиБ после распаковки** и до 450 файлов. После импорта APK по-прежнему **устанавливается отдельно системой Android**, а не запускается внутри виртуального контейнера. Для установки потребуется дополнительное место; XAPK/APKS/split APK не поддерживаются.
