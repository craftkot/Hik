# EHTID Game Lab Alpha 0.4.6 — Android

**Версия:** Android APK, интерфейс с оригинальной иконкой и тёмно-фиолетовой темой.

## Установка

1. Открой [GitHub Releases](https://github.com/craftkot/Hik/releases) и скачай установочный APK последнего выпуска напрямую. Ссылки Actions Artifacts не требуются.
2. Установи скачанный `EHTID-GameLab-Android-v*.apk`. На Xiaomi/POCO система может предложить подтвердить установку из доверенного источника.
3. Открой **Читы (соло)** — здесь находится управление плавающим значком.
4. Нажми **«Запустить поверх игры»**. При первом запуске появятся системные настройки **«Показывать поверх других приложений»**. Разреши для EHTID, вернись в приложение и повторно нажми кнопку.
5. Значок **E** можно перетаскивать поверх других приложений. Нажми на него, чтобы открыть панель. Введи видимые на экране HP, ману или валюту. Кнопка **«Открыть редактор»** возвращает в EHTID и передаёт введённое число. Кнопки **«−»** и **«×»** сворачивают и останавливают окно.
6. При необходимости открой папку сейвов через системный Android SAF-picker и ищи указанное значение в **доступных** файлах. Для текстовых/JSON и некоторых бинарных сейвов можно подтвердить точечное изменение с резервной копией.

## Чего Android-оверлей не делает

Это плавающее окно для ручного ввода, **не универсальный чит для других Android-игр**. Обычное приложение Android не может читать или менять оперативную память другой игры. Никакие обходы sandbox/root/античита не встроены. Панель не читает скрыто содержимое чужих окон, не делает тайных скриншотов и не видит HP без твоего ввода.

Для считывания числа со снимка можно воспользоваться обычным системным скриншотом и кнопкой выбора изображения в редакторе; на Android в этой версии нет встроенного автоматического OCR чужого экрана. Для доступа к Android/data, Android/obb и закрытым файлам игр могут действовать системные ограничения, даже после выбора папки.

## Защита и ограничения

- Не меняй сейв, когда игра продолжает в него писать.
- Сделай копию профиля перед испытанием альфы.
- Если игра использует шифрование/сжатие/контрольные суммы, поиск числа может ничего не найти.
- Системное разрешение оверлея можно отозвать в **Настройки → Приложения → Специальный доступ → Поверх других окон** (названия пунктов различаются).
- Оверлей работает как видимая фоновая служба, оставляет уведомление и останавливается кнопкой «×» или «Остановить» в приложении. Если телефон выгрузит службу из-за экономии батареи, запусти её снова.
- Некоторые полноэкранные приложения не отображают сторонние оверлеи из-за своей политики защиты или системных ограничений.

## Проверка поиска по нескольким папкам (исправление Alpha)

1. В EHTID выбери **папку A**, содержащую копию небольшого читаемого сейва; программа должна показать файлы.
2. Через значок папки с плюсом добавь **папку B**, содержащую другой сейв. Системные разрешения Android предоставь отдельно для каждой папки.
3. Найди известное число в файле A, затем открой файл B, затем **снова файл A**. Оба должны читаться без ошибки «Document not found».
4. Для проверки безопасной записи используй **тестовый сейв**: в папке A измени выбранное значение. Редактор должен создать резервную копию **в папке A**, а не B.
5. Пересканируй папки и проверь, что всё ещё можно открыть файлы каждой из них. После перезапуска приложения папки необходимо снова добавить в список, даже если Android сохранил системные разрешения.

Важно: выбор одной папки **не даёт доступа ко всем файлам телефона**; Android может ограничивать выбор отдельных системных или игровых директорий. Если провайдер отозвал разрешение, повторно выбери нужную папку.


## Проверка изменений сейвов в Alpha 0.4.3

Редактор теперь передаёт исходные байты сохранения системному SAF-модулю и повторно сверяет их **до создания/записи резервной копии и непосредственно перед изменением оригинала**. Если игра успела обновить сейв, запись прервётся, чтобы не затереть новые данные. Разрешения Android по-прежнему распространяются только на выбранные папки.

## Приоритетные значения в сейвах (Alpha 0.4.5)

В редакторе JSON-полей доступных Android-сейвов значения, похожие по названию на валюту, HP, ману, характеристики, опыт и уровень, помечаются и выводятся выше остальных. Поиск по выбранным через SAF папкам также выделяет явные числовые присваивания. Это **подсказка по имени поля**, а не доказательство назначения значения в игре. Сортировка не меняет сами файлы и не предоставляет доступ к RAM чужих приложений.

## Фильтрация полей JSON — Alpha 0.4.6

В редакторе сохранений открой JSON-файл и нажми **«Редактировать поля JSON»**. Вверху окна найди поле **«Поиск по ключу или значению»**, переключатель **«Только важные»** и категории («Валюта», «HP / здоровье», «Мана / MP», «Характеристики», «Уровень», «Опыт», «Ресурсы»). Фильтры можно сочетать; кнопка **«Все»** отменяет выбор категории. Если совпадений нет, нажми **«Сбросить фильтры»**. Нажатие по полю открывает прежний редактор с подтверждением. Никаких автоматических изменений или записи в сейв фильтрация не выполняет.
