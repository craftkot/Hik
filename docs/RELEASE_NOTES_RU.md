# EHTID Game Lab — Alpha 0.4.8 · Windows + Android

**Новое в Android:** выбор установленной игры из списка вместо обязательного поиска её папки. EHTID предлагает игровые файлы, найденные среди уже доступных SAF-каталогов, и умеет запомнить вручную разрешённую папку для конкретной игры.

## Установка

На странице [GitHub Releases](https://github.com/craftkot/Hik/releases) открой выпуск **v0.4.8-alpha.1** и скачай:

- **Android:** `EHTID-GameLab-Android-v0.4.8-alpha.1.apk`.
- **Windows 10/11 x64:** `EHTID-GameLab-Windows-x64-v0.4.8-alpha.1.zip`.
- Хеши SHA-256 и русскую инструкцию можно найти в Assets выпуска.

## Android: поиск сохранений через выбор игры

1. В верхней панели редактора нажми **«Игра»**.
2. Найди приложение по названию или идентификатору пакета (например, `com.example.game`).
3. EHTID сканирует только каталоги, на доступ к которым ты ранее согласился через системный Android SAF. Название папки/файла сравнивается с игрой.
4. Если файлов не найдено, нажми значок папки рядом с выбором игры. Разреши доступ к публичной папке выбранной игры. EHTID запомнит привязку и при следующем выборе игры проверит эту папку автоматически.
5. Найденные кандидаты появляются в редакторе вне зависимости от расширения файла; проверяй содержимое и перед записью используй резервную копию.

**Ограничение Android:** выбор установленного приложения не даёт доступ к его приватным сейвам в `/data/data`, закрытых `Android/data` и `Android/obb`. Без системного доступа/root обычный APK не может автоматически читать такие файлы. Программа не запрашивает `QUERY_ALL_PACKAGES`, не обходит sandbox и не вмешивается в чужие онлайн-игры. Совпадение имени файла не гарантирует, что это настоящее сохранение.

## Что сохранено из 0.4.7

Windows RAM-редактор с режимом безопасного обновления значений, ручной оверлей, поиск и изменение офлайн-значений с подтверждением; Windows/Android редактор JSON, сортировка HP/валюты/маны, поиск чисел, резервные копии и защищённая запись. Android плавающее окно по-прежнему не является RAM-читом.

## Проверки

Добавлены тесты списка приложений, поиска в пределах пользовательских SAF-разрешений, сопоставления имени игры с путём, привязки папки и поискового диалога. Автоматическая сборка проверяет Android APK и Windows portable; реальную совместимость с сохранениями конкретных игр нужно проверить отдельно.
