# EHTID Game Lab — Alpha 0.4.3 · Windows + Android

**Новый выпуск после 0.4.2.** Основная цель этой версии — сделать изменение игровых сохранений безопаснее и понятнее. Работа над Windows-читами и Android-оверлеем продолжается, переводчик пока отложен до завершения этих двух направлений.

## Скачать

Открой [GitHub Releases](https://github.com/craftkot/Hik/releases) и выбери `v0.4.3-alpha.1`.

- **Windows 10/11 x64:** `EHTID-GameLab-Windows-x64-v0.4.3-alpha.1.zip`. Распакуй весь архив и запусти `game_lab.exe`. В ZIP находятся интерфейс, `EHTID-MemoryHelper.exe`, `EHTID-Overlay.exe`, Flutter-библиотеки, иконка и русская инструкция.
- **Android:** `EHTID-GameLab-Android-v0.4.3-alpha.1.apk`. Установи APK напрямую. Для плавающего окна разреши показ поверх приложений в настройках Android. Отдельная русская инструкция находится в Assets.
- **Проверка загрузки:** сравни SHA-256 файлов с `SHA256SUMS.txt`, приложенным к релизу. На Windows можно использовать `Get-FileHash -Algorithm SHA256 имя.zip`.

## Изменения в версии 0.4.3

- **Windows — безопаснее редактор сейвов.** Перед записью сверяются исходные байты. Программа создаёт и проверяет резервную копию, подготавливает новый файл рядом с оригиналом и проверяет его до замены. После установки файла выполняется повторное чтение. При ошибке во время двухэтапной замены программа пытается восстановить оригинал.
- **Windows — защита от случайной потери данных.** Если игра успела изменить сейв за время подготовки, операция отменяется. Временные `.ehtid-pending-*.tmp`, `.ehtid-rollback-*.tmp` и резервные `.ehtid-backup-*.bak` исключены из игрового поиска.
- **Android — сверка данных перед SAF-записью.** Нативная часть повторно проверяет открытые байты перед созданием резервной копии и перед изменением файла, чтобы снизить риск перезаписи обновлённого игрой сейва.
- **Регрессионные тесты.** Проверяется успешная запись, отказ при устаревших данных, сбой до установки нового файла, сбой во время переноса исходника, сбой после установки и сохранение сторонних изменений файла.
- **Ссылки и инструкции.** В документации используются постоянные GitHub Releases вместо ссылок на временные Actions Artifacts.

## Что сохранилось из 0.4.2

Windows-редактор памяти для одиночных офлайн-игр: поиск Int32/Int64/Float32/Float64, уточнение по точному значению и фильтры «изменилось / не изменилось / увеличилось / уменьшилось», проверка перед точечной записью и попытка отката. Плавающая WinForms-панель работает поверх обычных и безрамочных окон. Android-оверлей позволяет вручную вводить число и переходить к поиску в разрешённых файлах сохранений.

## Ограничения

Это **альфа**. В Windows подмена файла сделана как **восстанавливаемая последовательность двух переименований, а не атомарная транзакция**. При внезапном отключении питания между этапами рядом может остаться исходник под именем `.ehtid-rollback-*.tmp`. Не удаляй его и резервные копии — восстанови исходное имя сейва вручную после закрытия игры. Лучше всегда менять сейвы, когда сама игра закрыта.

На Android обычный APK не умеет читать или менять оперативную память чужих приложений. Нет обхода античита, DRM или серверных значений. Скриншот/OCR не даёт достоверной связи между цифрой на экране и адресом памяти. Совместимость с конкретными играми проверяется отдельно от GitHub CI.
