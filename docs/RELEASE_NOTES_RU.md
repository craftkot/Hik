# EHTID Game Lab — Alpha 0.4.6 · Windows + Android

**Удобнее находить важные значения в игровых сохранениях.** После выпуска 0.4.5, где HP, деньги, мана, уровень и статы получили приоритет в списках, в 0.4.6 добавлены независимые фильтры по категориям и поиск по значениям в окне JSON-полей.

## Скачать

После успешных проверок Windows и Android новый выпуск публикуется на [GitHub Releases](https://github.com/craftkot/Hik/releases) под тегом **v0.4.6-alpha.1**.

- **Windows x64:** `EHTID-GameLab-Windows-x64-v0.4.6-alpha.1.zip`; распакуй архив целиком и запусти `game_lab.exe`.
- **Android:** `EHTID-GameLab-Android-v0.4.6-alpha.1.apk`; скачай и установи APK напрямую.
- **Документы:** русская инструкция по Android и Windows (в ZIP), `SHA256SUMS.txt` для сверки целостности.

## Изменения

1. **Фильтры категорий в JSON:** «Валюта», «HP / здоровье», «Мана / MP», «Характеристики», «Уровень», «Опыт» и «Ресурсы». В списке показываются только категории, действительно найденные среди отображаемых полей.
2. **Переключатель «Только важные»:** скрывает технические поля и оставляет значения, предварительно распознанные по имени. Его можно сочетать с поиском и категориями.
3. **Поиск по имени ключа и значению:** например `hp`, `gold`, `strength` или `100`; есть очистка запроса, счётчик результатов и сброс фильтров при отсутствии совпадений.
4. **Общая реализация для Windows и Android:** один браузер полей использует уже отсортированный список; прежние ручное редактирование JSON, подтверждение изменения, безопасная запись и бэкапы сохраняются.
5. **Тесты:** проверка сочетания фильтров, сохранения путей JSON Pointer, открытия правильного поля, переключения категорий и пустых результатов. Для JSON локализации остаётся обычный поиск без категорий игрового сейва.

## Ограничения

Сортировка по «важности» и категории — подсказки по названиям, а **не достоверное определение механик игры**. Неизвестные бинарные значения автоматически не получают названия HP или денег. Режимы фильтров **ничего не записывают** до отдельного подтверждения редактирования и сохранения. При шифровании/сжатии файла может понадобиться отдельный адаптер. В Windows читы RAM работают только с локальными одиночными играми; Android не получает универсального доступа к оперативной памяти других приложений без специальных системных прав. Совместимость с конкретными играми требует проверки на устройствах.

После стабилизации читов и редактора сейвов продолжается разработка отдельного переводчика.
