# EHTID Game Lab 0.4.13 Alpha — большие APK на Android

## Что исправлено

Раньше функция **«Контейнер игр» → «Импорт ZIP / APK»** ошибочно ограничивала **обычные APK 200 МБ**. В этой версии APK можно импортировать размером **до 8 ГиБ** при наличии свободного места.

- Копирование APK в папку EHTID выполняется **потоком**, небольшими блоками по 256 КиБ, без загрузки файла в оперативную память целиком.
- В интерфейсе показаны **скопированные МиБ и проценты** (если файловый провайдер Android сообщил размер). Если размер неизвестен, отображается объём скопированных данных.
- Перед копированием проверяется свободное место в разделе приложения. EHTID оставляет **минимум 256 МиБ запаса**, включая проверку во время импорта. При нехватке места импорт прерывается, а недописанный каталог удаляется.
- Одновременно два импорта запустить нельзя.
- Для **HTML5 ZIP** остаётся прежний безопасный лимит: **200 МиБ на архив**, **50 МиБ после распаковки**, максимум **450 файлов**.
- Режим существует **только в Android**; функциональность Windows-редактора не меняется.

## Как попробовать

1. Установи `EHTID-GameLab-Android-v0.4.13-alpha.1.apk`.
2. Открой **«Контейнер игр» → «Импорт ZIP / APK»**, выбери свой файл `.apk` размером больше 200 МБ.
3. После выбора следи за индикатором копирования. Исходный APK не изменяется.
4. Когда копирование закончится, нажми **«Установить через Android»** и подтверди установку через системный диалог. Если Android запросит разрешение на установку из EHTID, выдай его и повтори команду.
5. В списке можно удалить только **внутреннюю копию APK** после установки, освободив место. Сама установленная игра при этом не удаляется.

### Ограничения

**Это всё ещё не виртуализация Android APK:** в контейнере хранится копия установщика, но установленная игра получает собственный Android UID и приватные данные, которые EHTID не может свободно читать. Реальный запуск на POCO X6 Pro отдельно от GitHub CI ещё не проверен. При установке Android может потребовать дополнительное свободное место; чтобы безопасно импортировать APK размером 1,5 ГиБ, потребуется по меньшей мере приблизительно столько же свободной памяти только для хранения копии **плюс** место для системной установки. Сохрани резерв перед началом.

Поддерживаются одиночные валидные `.apk`. Форматы `.xapk`, `.apks`, `.apkm`, наборы split APK и игровые ресурсы в отдельных OBB не поддерживаются этим импортом. Импорт файла размером 8 ГиБ не означает, что Android сможет его установить; это проверяется системным установщиком.
