# EHTID Game Lab — Alpha 0.4.4 · Windows + Android

**Новый выпуск с интерфейсом восстановления сейвов на Windows.** Включает все изменения основной ветки после 0.4.3: защиту при аварийном откате, ограничения чтения и новый управляемый пользователем предпросмотр резервной копии.

## Файлы выпуска

Открой [GitHub Releases](https://github.com/craftkot/Hik/releases) и выбери тег **v0.4.4-alpha.1**.

- **Windows x64:** `EHTID-GameLab-Windows-x64-v0.4.4-alpha.1.zip`. Распакуй ZIP целиком и запусти `game_lab.exe`. Внутри `EHTID-Overlay.exe`, `EHTID-MemoryHelper.exe`, Flutter-библиотеки и `START_HERE_RU.md`.
- **Android:** `EHTID-GameLab-Android-v0.4.4-alpha.1.apk`. Установи APK напрямую. Инструкция доступна отдельным файлом в Assets релиза.
- **SHA256SUMS.txt:** SHA-256 для ZIP и APK.

## Что нового

1. **Восстановление Windows-сейва прямо из интерфейса.** Открой сохранение, нажми «Восстановить резервную копию», выбери запись и проверь размер, время и первые байты бэкапа. Только после отдельного подтверждения файл будет восстановлен.
2. **Защита от устаревших предпросмотров.** При восстановлении перепроверяются и текущий файл, и выбранный бэкап: изменение любого из них между просмотром и записью отменяет операцию.
3. **Сохранение предыдущего состояния.** Перед восстановлением создаётся и проверяется новый бэкап текущего сейва. После успешной записи редактор перечитывает восстановленные данные.
4. **Безопасность после прерванной записи.** Обнаружение аварийных файлов `.ehtid-rollback-*.tmp` блокирует новые записи. Режим предпросмотра аварийных данных ограничен 32 файлами и общим объёмом 32 МиБ. Автоматическое удаление аварийных файлов не выполняется.
5. **Контроль размера.** Windows-редактор ограничивает чтение изменяемых сейвов, бэкапов и временных файлов 8 МиБ; увеличение файла игрой во время работы больше не вызывает неограниченное чтение.
6. **Регрессионные проверки.** Включены тесты отказа при устаревшем сейве и бэкапе, восстановления после подтверждения, выбора бэкапов только нужного файла и блокировки восстановления при незавершённом откате.

## Возможности, сохранённые из прошлых версий

Windows RAM-поиск для локальных одиночных игр: Int32/Int64/Float32/Float64, уточнение по точному числу либо «увеличилось/уменьшилось/изменилось/не изменилось», отдельные значения адресов, точечная запись с проверкой и попыткой отката. Плавающий Windows-оверлей работает над оконными и безрамочными играми.

Android: плавающая панель для ручного ввода числа, редактор доступных через SAF сейвов, несколько папок со своими разрешениями. На Android обычный APK не умеет редактировать оперативную память чужой игры без отдельной привилегированной интеграции.

## Ограничения

Это **альфа**, совместимость с конкретными играми не подтверждена. Закрой игру до правки сейва, сохрани резервную копию профиля. Windows использует проверяемую последовательность переименований, не гарантирует атомарность при аварийном выключении питания. Аварийные файлы нельзя удалять, пока не определён корректный исходник. Восстановление из бэкапа через интерфейс пока поддерживается **только на Windows**; Android-аналог планируется отдельно. Оверлей не обходит DRM, античит и защиту операционной системы. Переводчик будет следующим этапом после стабилизации читов и сейв-редактора.
