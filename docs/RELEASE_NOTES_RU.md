# EHTID Game Lab 0.4.20 Alpha — стабильный порядок резервных копий

В Windows-списке восстановления сейвов бэкапы с одинаковым временем изменения теперь сортируются дополнительно по имени файла. Это устраняет случайные перестановки записей на файловых системах с грубой точностью времени. Проверка добавлена в `desktop_save_recovery_test.dart`; чтение, подтверждение и безопасный откат не менялись.

# EHTID Game Lab 0.4.19 Alpha — числовой редактор INI/CFG-сохранений Windows

В разделе **«Редактор сохранений»** можно открыть текстовые файлы сохранений с расширениями **.ini** и **.cfg** и нажать **«Редактировать числовые поля INI»**. Кнопка появляется только в Windows, если файл содержит распознанное имя сохранения (save, slot, player, profile, character), находится в явно выбранном каталоге сохранений либо был найден автопоиском. Произвольные конфиги игры не выдаются за сейвы.

Появится упорядоченный список числовых ключей и секций. Подсказки по именам ставят **валюту, HP, ману, характеристики, уровень, опыт и ресурсы** выше технических чисел. Можно искать по секции, ключу и числу, а также включить «Только важные». Это только подсказки по названию — приложение не утверждает, что найденный ключ является настоящим HP игры.

Выбери число, введи новое и нажми **«В предпросмотр»**. Программа заменит только цифры выбранной записи, оставив без изменений секции, другие ключи, пробелы, комментарии `; ...` и `# ...`, порядок строк и переводы CRLF/LF/CR. Следующий шаг — привычная отдельная команда **«Применить»**: EHTID проверяет, что оригинал не изменился, создаёт резервную копию и перечитывает записанный результат. Лучше закрыть игру до записи.

**Ограничения:** редактируются только простые конечные целые или дробные числа после `key = value`. Не поддерживаются бинарные сейвы, зашифрованные файлы, SQLite, наборы массивов, специфические INI-диалекты, продолжения строк, значения с escape-последовательностями, checksum/подписи; такие строки остаются в обычном текстовом просмотрщике. Целые не превращаются в дробные. При неоднозначности и при изменении исходной строки адресная правка отменяется. Текстовый файл должен быть валидным UTF-8 и не более 8 МиБ.

Это расширение **только Windows-редактора**. Android-контейнер не изменялся. Старые JSON/бинарный поиск, переводчик, RAM-панель и оверлей остаются в portable ZIP.

## Проверки

Добавлены регрессионные тесты: приоритет полей, повторяющиеся ключи в разных секциях, CRLF и комментарии, сохранение остального файла побайтово, запрет подмены строк и некорректных чисел, поведение поискового окна.

# EHTID Game Lab 0.4.18 Alpha — Windows: перевод .lang и .properties

## Новые текстовые форматы локализации

В Windows-разделе **«Перевод игры»** теперь поддерживаются не только JSON, но и обычные текстовые файлы локализации **`.lang`** и **`.properties`**. Это полезно для ряда Java-игр, модов и игр, использующих ключи вида `menu.start=Start game`.

Для безопасности EHTID предлагает перевод только для файлов в каталогах `lang`, `locales`, `i18n`, `localization`, `translations` и нескольких известных имен локализаций. Файлы из `config`, `settings`, `saves`, `userdata` и `backup` сознательно исключены.

### Как пользоваться
1. На ПК открой EHTID → **«Перевод игры»** и выбери папку локализации игры или мода.
2. Выбери подходящий файл `en_us.lang`, `strings.properties`, `messages.properties` или другое распознанное имя.
3. Укажи свой адрес **LibreTranslate /translate**, язык перевода и нажми **«Перевести до 100 строк»**.
4. EHTID изменит в **предпросмотре** только переводимый текст после `=` или `:`. Имена ключей, комментарии (`#`, `!`, `;`), пустые строки, отступы, CRLF/LF и большинство служебных значений остаются как были.
5. Проверь результат. Для записи отдельно нажми **«Применить»**, подтверди и получи проверенную резервную копию файла рядом с оригиналом. Если игра изменила файл после открытия, EHTID отменит запись.

Защищаются игровые маркеры `{player}`, `%1$s`, `\\n`, `\\r`, `\\t`, HTML-теги и цветовые коды вроде `§a` и `&b`. Если переводчик потеряет токен, пытается вставить новый физический перевод строки или меняет непонятные escape-последовательности, небезопасная запись не выполняется. Unicode escape `\\uXXXX` и многострочные continuation-строки пропускаются без изменения.

### Ограничения
- **Не** заявлена поддержка произвольного `.ini`, `.po`, `.resx`, `.locres`, двоичных таблиц или Java `.properties` в нестандартной кодировке. Требуется корректный **UTF-8**; невалидные текстовые данные не передаются переводчику.
- В первом проходе до **100 строк**, файл до **1 МиБ**. Слишком длинные или технические строки пропускаются.
- EHTID **не изменяет APK, игровые движки и чужие защищённые каталоги**, не распаковывает проприетарные ресурсы автоматически.
- Сетевой перевод отправляет отдельные текстовые строки только на **указанный пользователем** LibreTranslate-сервер. Сам файл туда не загружается.
- Разработка Android-контейнера остаётся приостановленной. Это улучшение предназначено для **ПК-версии**.
