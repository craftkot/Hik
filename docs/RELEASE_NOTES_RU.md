# EHTID Game Lab — Alpha 0.4.7 · Windows + Android

**Новая функция Windows:** обновление показаний ранее найденных RAM-адресов без изменения памяти игры. Теперь легче отличать настоящие HP, ману или валюту от совпавших чисел по изменению значения, не рискуя случайной записью.

## Загрузка

После успешных проверок новый выпуск появляется в [GitHub Releases](https://github.com/craftkot/Hik/releases) с тегом **v0.4.7-alpha.1**.

- **Windows 10/11 x64:** `EHTID-GameLab-Windows-x64-v0.4.7-alpha.1.zip` (включает редактор сейвов, `EHTID-MemoryHelper.exe`, `EHTID-Overlay.exe`, Flutter и инструкцию).
- **Android:** `EHTID-GameLab-Android-v0.4.7-alpha.1.apk` (Android SAF-сейвы, плавающее окно ручного ввода чисел, приоритет и фильтры JSON).
- **Инструкция** на русском и `SHA256SUMS.txt` приложены к релизу.

## Изменения

1. **Чтение текущих RAM-показаний.** После точного поиска нажми **«Обновить показания»**. Помощник перечитает до 5000 ранее найденных адресов без повторного полного сканирования; для каждого кандидата вернёт актуальное числовое значение.
2. **Безопасный режим наблюдения.** Чтение использует только разрешённый Windows доступ на чтение, не вызывает команды записи. Все кандидаты с доступными конечными числами остаются в списке независимо от того, выросло значение, уменьшилось или осталось прежним.
3. **Состояние недоступных адресов.** Адреса, переставшие читаться, и NaN/Infinity для Float32/64 исключаются; интерфейс сообщает их число. Это не означает, что приложение определило реальный HP автоматически.
4. **Плавающий Windows HUD.** Добавлен режим «Обновить показания» в выпадающий список сравнений; список показывает не только адрес, но и последнее считанное значение. Запись и откат по-прежнему выполняются по одному выбранному адресу с проверкой старого числа.
5. **Самопроверки.** .NET helper selftest проверяет сохранение кандидатов как с изменившимися, так и с неизменными значениями; Flutter unit-тесты проверяют режим и значения снимка.

## Что сохранено

Кроссплатформенный редактор JSON и локальных сейвов с категориями «HP», «валюта», «мана», «характеристики», фильтрами и поиском по полю, резервными копиями и защитой от устаревших записей. Windows имеет восстановление сейва из бэкапа с подтверждением. Android использует SAF для разрешённых пользователем папок; не может без особых привилегий редактировать оперативную память других игр.

## Важные ограничения

**Это альфа-версия.** Режим чтения RAM не является постоянным мониторингом в фоне, не ищет указатели и не определяет автоматически смысл адреса. После перезапуска игры или выгрузки уровня адреса могут измениться. Операции недоступны для защищённых процессов, читов в онлайн-играх и обхода античита/DRM. Новые игры и устройства требуют отдельной проверки; CI подтверждает сборку и тесты, но не реальную совместимость.

После стабилизации Windows-читов и сейв-редактора продолжим разработку отдельного переводчика игровых ресурсов.
