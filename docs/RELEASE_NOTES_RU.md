# EHTID Game Lab — Alpha 0.4.11 · Android manual folder fallback

## Android: игра отсутствует в списке — ручной выбор папки

Для Android основной путь теперь **«Папка»** в верхней панели редактора и переводчика. Приложение откроет системный выбор папки, и пользователь может разрешить доступ к доступной общей директории игры.

- В списке установленных игр также есть отдельная кнопка **«Нет игры? Выбрать папку вручную»**. Если список вообще пуст, EHTID открывает системный выбор папки вместо пустого результата.
- Ручной редактор показывает **все доступные файлы выбранной папки**, а не только файлы с типичными именами `save`, `player` или расширениями `.json`, `.sav`. Пользователь сам проверяет, какие из них являются сейвами.
- Переводчик допускает ручной выбор папки **без выбора установленной игры**. Он по-прежнему ограничивает перевод доступными JSON-локализациями и требует подтверждения изменений с резервной копией.
- Кнопка поиска установленных приложений остаётся дополнительным вариантом; если конкретная игра видна, выбор по package ID продолжает работать.

**Важно:** системный SAF не позволит открыть многие защищённые `Android/data`, `Android/obb` или внутренние `/data/data`. Разрешение «Управление всеми файлами» расширяет доступ к общим файлам, но не снимает эти ограничения. Приложение не использует root и не обещает читать скрытые сейвы.

Остальные возможности 0.4.10, включая запрос разрешения, перевод ML Kit и редактор сохранений, сохранены.
