# EHTID Game Lab — Alpha 0.4.16 · Float32 RAM safety

Windows RAM: ненулевые значения Float32 меньше минимального представимого положительного числа отклоняются вместо молчаливого превращения в ноль. Добавлены регрессионные тесты для положительных и отрицательных чисел, нуля и Float64.

После успешного CI релиз v0.4.16-alpha.1 должен содержать Windows ZIP, Android APK, русскую инструкцию и SHA256SUMS.txt. До публикации использовать предыдущий проверенный выпуск.

# EHTID Game Lab — Alpha 0.4.10 · Android permission update

## Android: доступ ко всем файлам

Теперь в разделах работы с игровыми файлами отображается явный запрос **«Доступ ко всем файлам»** на Android 11 и новее, пока разрешение не выдано.

1. Нажми **«Выдать разрешение»**.
2. Android откроет **специальный доступ к файлам** для EHTID Game Lab. Включи переключатель **«Разрешить управление всеми файлами»** (название зависит от Android / HyperOS).
3. Вернись в EHTID. Приложение автоматически повторно проверит статус. После выдачи разрешения напоминание пропадает.
4. Если пользователь отказал, редактор и переводчик продолжают работать с файлами из вручную разрешённых папок через системный SAF.

Разрешение `MANAGE_EXTERNAL_STORAGE` даёт доступ к **общему файловому хранилищу** телефона для чтения и записи через файловые API. Это **не** доступ к приватным данным `/data/data`, запрещённым директориям чужих приложений в `Android/data` и `Android/obb` или к памяти процессов. Текущие механизмы поиска и редактирования EHTID **пока используют SAF-папки**: одно предоставление широкого разрешения само по себе не заставит программу автоматически находить все сейвы чужих игр. Дальнейшее использование широкого доступа в автоматическом сканере — отдельная функция.

Android 10 и старее продолжают использовать SAF; запрашивать специальный доступ там нельзя. Системное разрешение пользователь может отозвать в настройках Android. Для распространения через Google Play это разрешение подчиняется дополнительным ограничениям публикации; APK предназначен для установки напрямую из GitHub Releases.

В версии сохранены выбор игры из 0.4.8, переводчик ML Kit / LibreTranslate из 0.4.9 и существующая защита резервными копиями.
