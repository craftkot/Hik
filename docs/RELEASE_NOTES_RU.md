# EHTID Game Lab — Alpha 0.4.2 (Windows + Android)

**Первый официальный GitHub Release**. Архивы сборок теперь прикрепляются к записи в разделе [Releases](https://github.com/craftkot/Hik/releases), а не к временным результатам GitHub Actions.

## Скачать и запустить

**Windows 10/11 x64:** скачай `EHTID-GameLab-Windows-x64-v0.4.2-alpha.4.zip`, распакуй весь архив в отдельную папку и запусти `game_lab.exe`. В ZIP входят `EHTID-Overlay.exe`, `EHTID-MemoryHelper.exe`, библиотеки Flutter, иконка и файл `START_HERE_RU.md` с инструкцией. Не запускай отдельный EXE прямо из архива.

**Android:** скачай `EHTID-GameLab-Android-v0.4.2-alpha.4.apk` прямо со страницы релиза, установи на телефон, в приложении открой «Читы (соло)». Плавающее окно можно запустить после явного разрешения Android «Показывать поверх других приложений». Android-инструкция также прикреплена к релизу отдельно.

**Целостность:** файл `SHA256SUMS.txt` содержит хеши сборок. На Windows можно проверить архив командой PowerShell `Get-FileHash -Algorithm SHA256 .\EHTID-GameLab-Windows-x64-v0.4.2-alpha.4.zip`.

## Что умеет эта альфа

- **Windows:** редактор локальных сейвов с проверкой, поиском числовых значений и резервными копиями. Точный поиск значений оперативной памяти одиночных игр в форматах Int32/Int64/Float32/Float64 с ручным выбором процесса и адреса.
- **Новый Windows-поиск:** последовательно отбирай кандидаты по условиям «изменилось», «не изменилось», «увеличилось» и «уменьшилось» (например после получения урона). Запоминается отдельное число для каждого адреса; запись требует явного подтверждения, проверки старого значения и повторного чтения результата.
- **Плавающая Windows-панель:** `EHTID-Overlay.exe` поверх оконных и безрамочных одиночных игр. Исключительный fullscreen может скрыть оверлей.
- **Android:** плавающий значок для ручного ввода HP/маны/валюты и возврата в редактор сохранений; несколько выбранных через Android SAF папок, безопасная привязка файлов к их исходным папкам.
- **Визуал:** тёмно-фиолетовая тема, оригинальная иконка EHTID, русские инструкции для обеих платформ.

## Ограничения

**Это тестовая версия.** Совместимость с конкретными играми не гарантируется и требует испытаний на устройстве. Android без root не может считывать или изменять RAM других игр; Android-оверлей работает только с введёнными пользователем числами и доступными файлами. Нет обхода античита, DRM и серверных данных. В Windows поиск по скриншоту помогает получить число, но **не находит адрес RAM автоматически**. Не трогай онлайн-игры и сделай копию сейва перед правкой.
