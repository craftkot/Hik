# EHTID Game Lab 0.4.12 Alpha — Android Container Lab

## Что проверяем

В этой версии появляется **отдельная вкладка «Контейнер игр» только на Android**. Windows-редактор и его процессы не менялись.

**Режим HTML5/ZIP — настоящий экспериментальный запуск внутри EHTID.** Программа импортирует ZIP с `index.html` в корне в закрытую папку EHTID (`filesDir/ehtid_container_lab/<id>/web`). Игру запускает собственный WebView, каждый экземпляр получает отдельный локальный HTTPS-адрес. Файлы доступны коду EHTID, а игровое сохранение в `localStorage` WebView сохраняется между запусками. JavaScript не получает Android bridge, доступ к `file://` отключён, внешние сетевые запросы в данном WebView блокируются.

**Режим APK — НЕ виртуализация.** APK импортируется и хранится в закрытой папке EHTID, но для установки открывается **системный установщик Android** (может потребоваться разрешить установку из EHTID). Установленная игра работает под собственным Android UID, сохраняет файлы в собственную защищённую область и **не отдаёт EHTID свои закрытые данные**. Плагины, XAPK, APKS, split APK не поддерживаются этим тестовым режимом. Это проверка импорта, обычной установки и запуска, а не запуск APK внутри EHTID.

## Тест за 2 минуты

1. Установи `EHTID-GameLab-Android-v0.4.12-alpha.1.apk` из GitHub Releases.
2. Открой новую вкладку **«Контейнер игр»**, нажми **«Создать тестовую игру»**.
3. В списке появится **EHTID Test — монеты**. Нажми **«Запустить внутри EHTID»**, несколько раз кнопку **«+1 монета»**.
4. Вернись назад, полностью закрой игровую вкладку и запусти тест снова. **Счётчик должен сохраниться.** Затем сбрось его и проверь повторное сохранение.
5. Для сторонней HTML5-игры подготовь ZIP с `index.html` в корне, открой **«Импорт ZIP / APK»** и выбери ZIP. Пакет должен быть до 200 МБ, после распаковки — до 50 МБ, максимум 450 файлов.
6. Для APK выбери **«Импорт ZIP / APK»** → обычный APK, затем **«Установить через Android»**. Разреши установку из EHTID, если потребуется, повтори действие и заверши установку в Android. Кнопка **«Запустить отдельно»** попробует открыть установленную игру вне контейнера.

## Ограничения и безопасность

- Контейнер HTML5 не поддерживает полноценный Android APK, нативные игровые движки, Google Play Services и игровые античиты.
- APK при обычной установке по-прежнему хранит приватные сейвы вне EHTID. Импорт APK внутрь папки EHTID не меняет модель разрешений Android.
- HTML5-игра может не работать, если ей нужны интернет, внешние ресурсы, нативные Android API или специфические функции браузера.
- Удаление импортированной копии HTML5-файлов не обязательно удаляет браузерный `localStorage` — это ещё экспериментальная версия. Удаление копии APK не удаляет саму установленную игру.
- ZIP распаковывается с лимитами числа файлов, размера и защитой от `../` (zip-slip). Подгруженные страницы не имеют JS-Android bridge. Не запускай подозрительные игры; экспериментальный контейнер ещё не является полноценной изоляцией.
- Выбор APK из неизвестного источника может быть опасен. Android проверяет и подтверждает установку системным диалогом.
- Тест физического телефона и совместимости реальных APK отдельно; успешная сборка CI этого не гарантирует.

## Дальнейший путь

Если этот опыт пройдёт, следующий этап — исследование настоящей виртуализации Android-приложений на уровне их процессов, `PackageManager`, ресурсов, сервисов и JNI. Простое копирование APK в свою папку не обеспечивает такой режим.
