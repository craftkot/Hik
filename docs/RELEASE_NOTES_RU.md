# EHTID Game Lab 0.4.14 Alpha — приоритет Windows

## Windows: поиск сейвов без выбора папки игры

В редакторе сохранений и переводчике на ПК появилась кнопка **«Найти сейвы»**. Раньше автопоиск был доступен только после того, как пользователь вручную откроет папку установки игры. Теперь:

1. Открой **«Редактор сохранений»** и нажми **«Найти сейвы»** даже без выбранной папки.
2. Введи **название игры** — например, `Stardew Valley` или `Sample Game`.
3. EHTID просканирует **только имена каталогов** в стандартных путях твоего пользователя: `%APPDATA%`, `%LOCALAPPDATA%`, `AppData\LocalLow`, `Saved Games`, `Documents`, `My Games` и `OneDrive\Documents`, если они существуют.
4. EHTID распознаёт `Game Name`, `GameName`, `GameName Saves`, `GameName SaveData` и вложенные папки вида `Roaming\Studio\GameName` или `LocalLow\Company\GameName`.
5. Перед доступом к найденным файлам показывает **точные пути и запрашивает подтверждение**. Если ранее ни одной папки не было, первая подтверждённая становится основной; остальные (до шести всего) подключаются как дополнительные.
6. Найденные сейвы открываются в существующем редакторе: важные поля JSON (валюта/HP/мана/статы), поиск чисел в бинарных файлах, резервные копии и подтверждение записи остаются доступными.

Если игровая папка уже была выбрана, EHTID попытается определить правильное название даже по установке вида `Game Name\Binaries\Win64`. Перед поиском можно изменить название вручную.

## Что не меняется

- Windows RAM-редактор и плавающий оверлей продолжают работать по-прежнему. Никакого автоматического вмешательства в процессы игр.
- Перевод JSON через собственный LibreTranslate-сервер остаётся доступным в разделе **«Перевод игры»**.
- Android-разработка приостановлена. В APK эта новая Windows-функция не показывается.
- Поиск не обходит Windows ACL, не раскрывает защищённые каталоги, не сканирует весь диск и не изменяет игровые файлы без последующего явного действия. Это поиск **по названию**, поэтому некоторые игры с нестандартным расположением или названием сейвов не найдутся.
- Релизные тесты выполняются через GitHub Actions. Для каждой конкретной игры совместимость подтверждается только ручным тестом на компьютере.

## Дополнительно

Если файлы сохранения не найдены, в редакторе остаётся **«Открыть папку игры»** для ручного выбора. Если важно сохранить данные, закрой игру перед редактированием; перед применением EHTID делает резервную копию и сверяет оригинал.
