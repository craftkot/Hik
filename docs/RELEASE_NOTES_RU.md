# EHTID Game Lab — Alpha 0.4.5 · Windows + Android

**Основное изменение:** в редакторе сейвов важные числовые поля теперь появляются первыми и выделяются визуально. Значения валюты, здоровья, маны и характеристик больше не приходится искать среди обычных технических ключей JSON.

## Где скачать

Открой [GitHub Releases](https://github.com/craftkot/Hik/releases) и выбери **v0.4.5-alpha.1**.

- **Windows x64:** `EHTID-GameLab-Windows-x64-v0.4.5-alpha.1.zip`. Распакуй весь архив и открой `game_lab.exe`. В комплекте Windows-оверлей, RAM-помощник и русская инструкция.
- **Android:** `EHTID-GameLab-Android-v0.4.5-alpha.1.apk`. Установи APK напрямую. Инструкция на русском — отдельным файлом в Assets.
- **SHA256SUMS.txt:** контрольные суммы APK и ZIP для проверки загруженных файлов.

## Что нового

1. **«Важное сверху» в JSON-сейвах.** В диалоге редактирования полей сначала идут выделенные значения категорий: валюта, HP/здоровье, мана/MP, характеристики, уровень, опыт и ресурсы. Остальные поля остаются доступными.
2. **Поддержка названий на русском и английском:** `gold`, `coins`, `money`, `health`, `hp`, `mana`, `str`, `strength`, `agility`, `level`, `xp`, `золото`, `здоровье` и другие. Есть распознавание `camelCase` и вложенных JSON-путей. Программа не выделяет случайные совпадения внутри слов вроде `shop` или `goldenRatio`.
3. **Приоритет важных результатов при поиске по файлам игры.** Для текстовых сейвов числовые значения с непосредственным именем ключа, например `"hp": 100` или `gold=100`, поднимаются выше неизвестных совпадений. Числа в бинарных файлах без известных имён по-прежнему показываются без ложного распознавания.
4. **Приоритет вероятно важных файлов в списке.** `playerStats.json`, `gold.sav` и аналогичные имена видны раньше остальных. Подсказка обозначена как предположение по имени файла.
5. **Для крупных JSON** просматриваются до 2500 первых листовых полей, после чего выводятся до 500 строк с приоритетом важного. Это ограничение относится только к быстрому списку: данные не удаляются, исходный редактор текста остаётся доступен.
6. **Тесты:** категории, русские и английские ключи, стабильная сортировка, правильный порядок UI, ложные совпадения, защита бинарных значений от неверной маркировки.

## Что осталось

Windows: безопасный редактор локальных сейвов, восстановление резервной копии с подтверждением, поиск и точечная правка RAM в своих одиночных играх, плавающая панель поверх оконного режима. Android: редактор файлов из разрешённых SAF-папок, ввод чисел через плавающую панель.

**Важно:** распознавание основано на названии ключа и не подтверждает его назначение в конкретной игре. Перед изменением проверяй результат и сохраняй бэкап. Шифрованные/сжатые сейвы и бинарные поля без семантических подсказок не расшифровываются автоматически. Android APK не получает доступа к RAM чужих игр. Обхода античита, DRM и серверных значений нет. Совместимость с конкретными играми требует отдельной проверки на устройстве.

После стабилизации читов и редактора сейвов продолжим отдельную разработку переводчика ресурсов.
