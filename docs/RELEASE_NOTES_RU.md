# EHTID Game Lab 0.4.15 Alpha — Windows RAM Watchlist

## Автоматическое чтение закреплённых адресов в одиночной игре

В **Windows → Читы (соло) → Live Memory** теперь можно наблюдать за несколькими найденными числовыми значениями, не запуская каждый раз поиск памяти заново.

1. Открой свою локальную одиночную игру в оконном или безрамочном режиме.
2. В EHTID нажми «Найти окна», выбери процесс, введи текущее число (например, HP = 100) и сделай «Первый поиск». При необходимости уточни результат.
3. В списке адресов нажми значок **звёздочки** рядом с подходящим адресом. Добавится панель **«Наблюдение»**; можно закрепить до **12 адресов**.
4. Нажми **«Читать каждые 2 сек»**. EHTID будет **только читать** эти 12 или меньше адресов раз в две секунды и показывать актуальные показания. Сканирование всей памяти при этом не выполняется.
5. Нажми **«Остановить чтение»**, чтобы приостановить. Кнопка удаления возле адреса убирает его из списка. При смене процесса игры, типа числа или поиске новых окон наблюдение сбрасывается.
6. Если игра закрыта, адреса стали недоступны или модуль памяти вернул ошибку, чтение автоматически останавливается и показывает причину.
7. Перед открытием ручной записи по адресу наблюдение останавливается, а запись по-прежнему требует отдельного подтверждения и проверки исходных байтов.

### Важные гарантии

- **Никаких автоматических правок RAM и заморозки показателей**. Автонаблюдение — только `compare(mode: all)` по уже найденным адресам; нет нового сканирования памяти в цикле.
- Показания в панели наблюдения **не перезаписывают базовые значения сравнения** для фильтров «изменилось», «выросло», «уменьшилось», поэтому фильтрацию можно продолжать вручную.
- Не более 12 адресов, интервал **2 секунды**, без запуска параллельных операций памяти. Любое сообщение об ошибке останавливает опрос.
- Все существующие ограничения Windows остаются: программа читает память только выбранного процесса с обычными разрешениями, не обходит античит/DRM, не даёт гарантии доступности адресов после загрузки другого уровня или перезапуска игры.
- Изменения **только для Windows-интерфейса**, Android-функциональность не расширялась. Проверка конкретной игры требует теста на реальном ПК.

## Установка

Скачай **полный portable Windows ZIP** из [GitHub Releases](https://github.com/craftkot/Hik/releases), распакуй его целиком и запусти `game_lab.exe`. В одном каталоге должны остаться `EHTID-MemoryHelper.exe` и `EHTID-Overlay.exe`.

В тестовом выпуске сохранены прежние редактор сейвов с резервными копиями, поиск папок сохранений Windows и перевод доступных JSON-локализаций.
