# EHTID Game Lab — Alpha 0.4.9 · Windows + Android

**Главное изменение Android:** теперь в разделе «Перевод игры» можно выбрать установленную игру и подготовить перевод её **доступных JSON-локализаций** на русский, в том числе без внешнего переводческого сервера — через Google ML Kit на устройстве.

## Загрузка

После успешной сборки выпуск появится на [GitHub Releases](https://github.com/craftkot/Hik/releases) с тегом **v0.4.9-alpha.1**:

- Android APK: `EHTID-GameLab-Android-v0.4.9-alpha.1.apk`.
- Windows 10/11 x64: `EHTID-GameLab-Windows-x64-v0.4.9-alpha.1.zip`.
- Русская инструкция и файл `SHA256SUMS.txt` находятся в Assets.

## Android: перевод игры

1. Перейди в **«Перевод игры»**, нажми **«Игра»** и выбери установленное приложение. EHTID просканирует ранее разрешённые пользователем папки и найдёт подходящие JSON-локализации.
2. Если файлы не найдены, нажми **«Доступ к папке игры»** и через системный Android-проводник разреши нужную открытую папку; EHTID запомнит её для этой игры.
3. По умолчанию выбран **«Перевод на телефоне (ML Kit)»**. Укажи **исходный язык** (EN/JA/ZH/KO), русский уже выбран как целевой. При первом переводе Android может скачать модели перевода; после загрузки обработка текста происходит на устройстве. Ключ API не нужен.
4. При желании отключи перевод на телефоне и укажи свой защищённый **LibreTranslate** сервер — в этом режиме строки отправляются выбранному серверу, а исходные файлы не отправляются целиком.
5. Нажми **«Подготовить перевод»**. Ограничение альфы: максимум **6 JSON-файлов и 100 строк на файл за запуск**, размер отдельного исходного файла до 1 МБ.
6. Просмотри изменения для каждого файла. Ничего не записывается до нажатия **«Сделать копии и применить»**. При записи используются резервные копии, повторная проверка оригинала и проверка JSON-структуры.
7. Закрой игру во время записи. После перезапуска проверь, использует ли она изменённую локализацию.

## Что поддерживается

- Открытые JSON-словари `locales/`, `lang/`, `localization/`, `i18n/` и распространённые названия `strings.json`, `en.json` и т. п.
- Не изменяются JSON-ключи, структура массивов, числа, булевы значения и `null`; проверяются текстовые плейсхолдеры.
- Сейвы, настройки и архивы не переводятся этим режимом по ошибке.
- Если часть файлов нельзя записать, программа сообщает об этом; успешно изменённые файлы имеют отдельные бэкапы.

## Ограничения

**Это не универсальный русификатор любого Android APK**: нет доступа к приватным данным чужой игры, защищённым Android/data или OBB, шифрованным/сжатым контейнерам, исполняемому коду и сетевым ресурсам. Некоторые игры не используют JSON-локализацию или перезаписывают изменённые файлы. ML Kit переводит машинно и может ошибаться в игровом контексте; исходный язык нужно выбрать вручную.

Функции Windows и существующий редактор сохранений из 0.4.8 сохранены. Реальное тестирование на конкретных Android-играх проводится отдельно от CI.
