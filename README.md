# EHTID Game Lab

Кроссплатформенная утилита для просмотра игровых файлов, редактирования доступных сохранений и локализаций. Поддержка Android и Windows.

Исходный код и сборка v0.3.0 добавляются. Текущий репозиторий используется по просьбе владельца.

Без реверса защищённых онлайн-игр и без обхода Android sandbox.
