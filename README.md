# EHTID Game Lab · v0.3.1

Проект для **Android и Windows** на Flutter. Работа с локальными файлами игр: просмотр ресурсов, JSON/текстовых сохранений, локализаций, архивов ZIP/APK/JAR. Поддержка нестандартных игровых форматов расширяется отдельными адаптерами.

## Состояние

- **Предзагрузки:** список доступных файлов, просмотр изображений, UTF-8, HEX, ZIP-содержимого (без обхода шифрования).
- **Сохранения:** редактор JSON-полей, проверка изменений, резервная копия перед записью, попытка восстановления при ошибке на Android.
- **Перевод:** перевод строк JSON через совместимый с LibreTranslate сервер, с проверкой плейсхолдеров.
- **Читы:** интерфейс и список Windows-процессов; запись в память пока не реализована.
- **Автоопределение движка:** эвристики для Unity, Unreal, Godot, Ren'Py и GameMaker.

## Исходники и сборка

Исходный проект v0.3.0 загружен в `.payload/00.b64`–`05.b64`. Workflow [Import v0.3 source and build Android + Windows](../../actions/workflows/import.yml) проверяет SHA-256, извлекает исходники в корень репозитория и собирает обе платформы. Если автоматический запуск не состоялся, включи GitHub Actions и запусти этот workflow через **Run workflow**.

После импорта файлы располагаются в `lib/`, `android_native/`, `test/`, `tool/` и `.github/workflows/build.yml`. Для последующих сборок — [Build Android APK and Windows app](../../actions/workflows/build.yml). Готовые сборки, если CI успешно завершился, появятся в **Actions → Artifacts**.

GitHub Actions создаёт платформенные каталоги перед сборкой с помощью `flutter create`. APK и EXE считаются **непроверенными**, пока нет успешного CI.

## Ограничения

Android SAF не предоставляет доступ к чужим приватным `Android/data` и `Android/obb`; защищённые ресурсы и проприетарные форматы не расшифровываются автоматически. Для первых тестов выбирай доступные папки или предоставленные пользователем файлы. Работа с онлайн-играми и античитом не предусмотрена.

## Редактирование бинарных сейвов (v0.3.1)

В разделе **Сохранения** открой доступный бинарный файл размером до 8 МиБ, нажми **«Найти и изменить число в сейве»**. Поддерживаются Int32 и Float32 в little/big endian, точный поиск числового значения, выбор смещения, подтверждение, проверка неизменности файла на диске, резервное копирование и повторное чтение результата. Никакие изменения не применяются автоматически ко всем совпадениям.

Это инструмент для обычных неупакованных локальных файлов: он не расшифровывает закрытые форматы и не исправляет игровые контрольные суммы. Для конкретных игр понадобятся адаптеры. Для Android недоступно чтение памяти чужой игры без специальных прав; данный режим работает только с выбранными файлами.


## Поиск по файлам игры (v0.3.2)

Вкладки **Редактор сохранений** и **Читы (соло)** теперь предлагают **«Поиск по файлам игры»**. Выбери начальную папку игры и при необходимости добавь другие через значок папки с плюсом в шапке (до шести доступных корней одновременно). **На Windows** можно нажать значок поиска папок в шапке: программа проверит **только имена каталогов** в `%APPDATA%`, `%LOCALAPPDATA%`, `AppData/LocalLow`, `Documents/My Games` и `Saved Games`, предложит совпадающие с названием игры и добавит их лишь после подтверждения. Также можно вручную выбрать папки установки и сохранений. **На Android** используй системный выбор папок SAF; приватные каталоги других приложений не становятся доступными без разрешения системы.

Поиск без изменений файлов просматривает доступные файлы до 8 МиБ: ищет текст без учёта регистра, а в бинарных файлах — Int32/Float32 в little/big endian. Результаты показывают файл, смещение байт или позицию символа, кодировку и предпросмотр. Есть прогресс, отмена, лимит 200 результатов и отчёт о пропущенных/недоступных файлах. Нажатие на результат откроет файл в редакторе, а применение правок потребует отдельного подтверждения и резервной копии.

Исполняемые файлы, большие ассеты, фото, видео и контейнеры сжатия в этот режим **не входят**. Закрытые/зашифрованные сейвы, SQLite-структуры и изменение памяти запущенных игр потребуют отдельных адаптеров. Никакой автоматической модификации всех совпадений.
